# 📥 00_Inbox - Cổng Nạp Tri Thức Nhanh (Frictionless Capture)

> Vùng đệm tiếp nhận ghi chú thô, ý tưởng thoáng qua, web clippings hoặc tóm tắt tài liệu trước khi được tinh chế và phân loại vào các Domain chuyên đề.

---

## 🧭 Quy Trình Xử Lý (Inbox Zero Protocol) 

1. **Nạp nhanh (Quick Dump):** Bất kỳ thông tin mới nào chưa rõ phân loại hoặc cần xử lý gấp $\to$ Lưu tạm tại `00_Inbox/`.
2. **Review định kỳ:**
   - Nếu là tài liệu gốc (RFC, Paper, Specs) $\to$ Chuyển sang `Sources/`.
   - Nếu là kiến thức chuyên sâu $\to$ Dùng AI hoặc tự biên soạn thành Atomic Note với Frontmatter chuẩn và chuyển vào đúng Domain (`DSA-learn`, `Database-knowledge`, `Backend-full-course`, `AI-knowledge`, `DevOps-knowledge`, `Network-CCNA`).
   - Xóa file thô sau khi đã chuyển hóa xong để đạt trạng thái **Inbox Zero**.
