### Q: 📝 5.1 Design an algorithm that **modifies** a list $L$ in-place, keeping **only the odd values** with a computational cost of $\boxed{O(n)}$ (without using the $\textsf{delete}$ primitive that scans the list from the beginning). Provide both the iterative and recursive versions. #card

?
**1. Iterative solution in $O(n)$:**
The iterative procedure traverses the list using a pointer $\textsf{tmp}$, checking at each step the value of the next node $\textsf{tmp.next}$. If $\textsf{tmp.next.val}$ is even, the node is removed by updating the pointer $\textsf{tmp.next} := \textsf{tmp.next.next}$ in $O(1)$ time; otherwise, the pointer $\textsf{tmp}$ simply advances to the next node.
Since this loop only checks nodes following $\textsf{tmp}$, the first node of the list is never inspected during the iteration: after the loop terminates, a separate check is performed on the head of the list $\textsf{L}$, updating it if it contains an even value.

```text
            // if (tmp.next.val 2 = 0) then
                // tmp.next := tmp.next.next

        // if (L.val 2 = 0) then
            // L := L.next
    // return L {aligned}
```

**2. Recursive solution in $O(n)$:**
At each level of the recursion, if the current node $\textsf{L}$ contains an even value, it is discarded by returning the result of the recursive call on $\textsf{L.next}$. If it is odd, its field $\textsf{L.next}$ is linked to the result returned by the recursion on $\textsf{L.next}$.

```text
{aligned}                            // OddList(L)
    // if L = NIL then
        // return NIL
    // if (L.val 2 = 0) then
        // return OddList(L.next)
    // else
        // L.next := OddList(L.next)
        // return L
```

📌 Note: both versions visit each node at most once, guaranteeing a computational cost of $\Theta(n)$.
