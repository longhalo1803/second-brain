### Q: 📝 What does it mean for a graph to be connected? What is the difference for directed graphs (connected vs strongly connected)?

Connectivity defines the ability to reach any node starting from another:

- **Connected undirected graph:** a path exists between every pair of nodes in the graph.
- **Connected (weakly) directed graph:** a path exists connecting every pair of nodes if the graph is considered ignoring edge directions.
- **Strongly connected directed graph:** a directed path exists both from $u$ to $v$ and from $v$ to $u$ for every pair of nodes $u, v \in V$.📝 Examples:
