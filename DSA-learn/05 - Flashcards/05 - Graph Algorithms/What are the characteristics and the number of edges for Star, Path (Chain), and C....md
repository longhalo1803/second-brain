### Q: What are the characteristics and the number of edges for Star, Path (Chain), and Cycle graphs? #card

?
Special graph structures with $n$ nodes:

- **Star:** a central node connected to all the other $n-1$ peripheral nodes.
  → Number of edges: $m = n - 1$
- **Path (or Chain):** nodes arranged in a linear sequence.
  → Number of edges: $m = n - 1$
- **Cycle:** nodes arranged to form a closed ring.
  → Number of edges: $m = n$
