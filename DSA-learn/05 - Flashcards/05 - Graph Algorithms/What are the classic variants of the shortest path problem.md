### Q: What are the classic variants of the shortest path problem? #card

?
The main variants are:

- **Point-to-point**: shortest path from a specific node to another specific node.
- **Single-source**: shortest paths from a source node $s$ to _all_ other nodes in the graph.
- **All-to-all (All-pairs)**: shortest paths from _every_ node to all other nodes in the graph.
