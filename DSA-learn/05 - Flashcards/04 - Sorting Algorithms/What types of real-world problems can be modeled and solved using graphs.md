### Q: What types of real-world problems can be modeled and solved using graphs? #card

?
Many real-world problems based on entities and relationships between them can be effectively modeled using graphs, for example for:

- **Dependencies and ordering of operations:** determining the correct order in which to perform tasks in a factory or put on clothes (modeled via topological sort).
- **Road networks and navigation:** computing the shortest path to travel between two cities (e.g., from Rome to Paris, modeled via shortest path algorithms).
- **Computer networks and Social Networks:** representing connections between devices or interaction relationships (e.g., friendships) between users.
