# 🎴 How are algorithmic problems classified based on the type of solution sought

### Q: How are algorithmic problems classified based on the type of solution sought? #card

?
Based on the type of solution sought, problems are classified into three main categories:

- **Decision problems:** the answer to the problem is a boolean value (YES or NO / True or False) depending on whether the INPUT satisfies a given property or not.
  📝 _Examples:_ graph connectivity test, decision binary search.
- **Search problems:** among all possible solutions, one is sought (called a _feasible solution_) that satisfies a given condition.
  📝 _Examples:_ binary search, sorting a sequence of numbers in ascending order, finding a spanning tree for a DFS in-order traversal.
- **Optimization problems:** each feasible solution is associated with a cost (via an objective function) and the _optimal solution_ is sought, that is, a feasible solution of minimum or maximum cost.
  📝 _Example:_ finding single-source shortest paths (e.g., Dijkstra's algorithm), data compression (Huffman Coding).
