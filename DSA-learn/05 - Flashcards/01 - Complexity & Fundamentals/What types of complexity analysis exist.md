# 🎴 What types of complexity analysis exist

> [[00 - Flashcards MOC|🎴 Master MOC]] / [[00 - Complexity & Fundamentals MOC|📁 Complexity & Fundamentals MOC]]

---

### Q: What types of complexity analysis exist? #card

?

- **Worst case**: upper bound for any input instance; we look for the smallest possible function to bound the maximum execution time. It is the most important analysis.
- **Average case**: often difficult to calculate as it depends on the probability distribution of input instances.
- **Best case**: lower bound, valid only for a specific instance or a small subset of inputs.
