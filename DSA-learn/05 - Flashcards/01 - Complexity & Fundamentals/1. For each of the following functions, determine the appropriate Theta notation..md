# 🎴 1. For each of the following functions, determine the appropriate Theta notation.

> [[00 - Flashcards MOC|🎴 Master MOC]] / [[00 - Complexity & Fundamentals MOC|📁 Complexity & Fundamentals MOC]]

---

### Q: 📝 1. For each of the following functions, determine the appropriate $\Theta$ notation.

(a) $4n + 1$
(b) $6n^3 + 12n^2 + 1$
(c) $2 \log n + 4n + 3n \log n$
(d) $3n^2 + 2n \log n$
(e) $(6n + 1)^2$
(f) $1 + 2 + 4 + 8 + 16 + \dots + 2^n$ #card
?
The exercises can be solved using (1) the algebraic rules of asymptotic notation and/or (2) the definition of asymptotic notations.

**(a)**
(1) $4n + 1$ is a first-degree polynomial, so it is $\in \Theta(n)$.
(2) We have $4n + 1 \ge 4n$ for all $n \ge 1$, thus $4n + 1 \in \Omega(n)$ ($c = 4$ and $n_0 = 1$).
Similarly, $4n + 1 \le 5n$ for all $n \ge 1$, thus $4n + 1 \in O(n)$ ($c = 5$ and $n_0 = 1$).
We conclude that $4n + 1 \in \Theta(n)$.

**(b)**
(1) $6n^3 + 12n^2 + 1$ is a third-degree polynomial, so it is $\in \Theta(n^3)$.
(2) We have $6n^3 + 12n^2 + 1 \ge 6n^3$ for all $n \ge 0$, thus $6n^3 + 12n^2 + 1 \in \Omega(n^3)$ ($c = 6$ and $n_0 = 0$).
Furthermore, $6n^3 + 12n^2 + 1 \le 6n^3 + 12n^3 + n^3 = 19n^3$ for $n > 0$, thus $6n^3 + 12n^2 + 1 \in O(n^3)$ ($c = 19$ and $n_0 = 1$).
We conclude that $6n^3 + 12n^2 + 1 \in \Theta(n^3)$.

**(c)** (2)
$2 \log n + 4n + 3n \log n \in \Omega(?) \iff c_1\cdot g(n) \le 2 \log n + 4n + 3n \log n \le c_2 \cdot g(n) \quad (n\ge1)$
We have $2 \log n + 4n + 3n \log n \ge 3n \log n$ (we choose the last term so that $g(n)$ matches the Big-O notation, see below), so
$2 \log n + 4n + 3n \log n \in \Omega(n \log n)$ ($c = 3$ and $n_0 = 1$) → lower bound.
Furthermore (upper bound), $2 \log n + 4n + 3n \log n \le 2n \log n + 4n \log n + 3n \log n = 9n \log n \in O(n \log n)$.
Therefore, $2 \log n + 4n + 3n \log n \in \Theta(n \log n)$.(1) By the hierarchy of growth rates ($\log n \ll n \ll n \log n \ll n^2 \ll 2^n$), the dominant term is $n \log n$, so the entire function belongs to that order for large $n$ (hence it is $\Omega(n\log n)$, as well as Theta and Big-O). We can also use the limit comparison test:$f(n) \in \Omega(n \log n) \iff \lim_{n \to \infty} \frac{2 \log n + 4n + 3n \log n}{n \log n} = \lim_{n \to \infty} \left( \underbrace{\frac{2 \log n}{n \log n}}_{\frac{2}{n} \rightarrow 0} + \underbrace{\frac{4n}{n \log n}}_{\frac{4}{n} \rightarrow 0} + \underbrace{\frac{3n \log n}{n \log n}}_{\frac{3n}{n} \rightarrow 3} \right)$
The limit ratio between the two functions is $3$, a positive non-zero finite constant, which means both functions grow at the exact same rate ($\Theta(n \log n)$).

**(d)** (2) We have $3n^2 + 2n \log n \ge 3n^2 \in \Omega(n^2)$ ($c = 3$ and $n_0 = 1$).
Furthermore, $3n^2 + 2n \log n \le 3n^2 + 2n^2 = 5n^2 \in O(n^2)$ ($c = 5$ and $n_0 = 1$).
Therefore $3n^2 + 2n \log n \in \Theta(n^2)$.

**(e)** (1) The function is a second-degree polynomial: $(6n + 1)^2 = 36n^2 + 12n + 1 \in \Theta(n^2)$.

**(f)** (2) $1 + 2 + 4 + 8 + 16 + \dots + 2^n = \underbrace{\sum_{i=0}^n 2^i}_{\small\text{geometric series}} = \frac{2^{\,n+1} - 1}{2 - 1} = 2^{n+1} - 1 \in \Theta(2^n)$ because $2^n \le 2^{n+1} - 1 \le 4 \cdot 2^n$, for $n \ge 1$.
