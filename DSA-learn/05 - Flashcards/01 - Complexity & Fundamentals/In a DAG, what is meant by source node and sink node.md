### Q: In a DAG, what is meant by source node and sink node? #card

?
In a DAG $G=(V,E)$:

- **Source node:** is a node that **has no incoming edges** (in-degree $= 0$).
- **Sink node:** is a node that **has no outgoing edges** (out-degree $= 0$).📌 Note: every finite DAG always has at least one source node and at least one sink node.
