### Q: What is pseudocode? #card

?
It is a high-level textual representation of an algorithm used as a middle ground between human language and an actual programming language to focus on logic without worrying about the specific syntax of a language.

It is not a language directly executable by a computer.
It is close to many high-level programming languages.
It allows different expressive means often close to spoken language.
It does not deal with low-level issues.
It allows focusing on the high-level solution.
