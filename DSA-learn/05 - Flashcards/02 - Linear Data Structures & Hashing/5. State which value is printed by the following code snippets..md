**(a)**
$c:=0$
for $i=2$ to 24 step 2
for $j=1$ to 24 step 2
$c:=c+1$
print $c$
**Solution.** The value of c that is printed is equal to the number of times the instruction $c:=c+1$ is executed, because the initial value of $c$ is zero and it is incremented by one each time the instruction is executed.
The innermost loop ($j$) executes the instruction 12 times (once for each odd number between 1 inclusive and 24 exclusive, because it stops at 23) and this loop is executed 12 times (once for each even number between 2 inclusive and 24 inclusive) by the outer one ($i$). The number of iterations is nevertheless the same for both loops.
Thus, we have $c=12\cdot12=144$.

**(b)**
$c:=0$
for $i=2$ to 27 step 1
for $j=i+1$ to 28
$c:=c+1$
print $c$
**Solution.**

$$
c=\sum_{i=2}^{27}\underbrace{\sum_{j=i+1}^{28}1}_{(a)}=\sum_{i=2}^{27}\underbrace{(28-(i+1)+1)}_{=28-i}=\underbrace{\sum_{i=2}^{27}28}_{(b)}-\underbrace{\sum_{i=2}^{27}i}_{(a)}=28\cdot26-\underbrace{\left[\frac{27\cdot28}{2}-1\right]}_{(c)}=728-378+1=351
$$

Indeed, in summation (a) $\sum_{j=i+1}^{28}1$ we add 1 for each $j$ between $i+1$ (inclusive) and $28$ (inclusive), which is $28-(i+1)+1=28-i$ times.
In summations (b) and (c) we must be careful because the index starts from 2: in (b) 28 is added $27-2+1=26$ times, while (c) does not include 1 (which must be subtracted from the sum of the first 27 natural numbers).

**(c)**
$c:=0$
for $i=0$ to 25 step 1
for $j=i+1$ to 25 step 1
$c:=c+1$
print $c$
**Solution.**

$$
\sum_{i=0}^{25}\sum_{j=i+1}^{25}1=\sum_{i=0}^{25}\big(25 - (i + 1) + 1\big)=\sum_{i=0}^{25}(25-i)=\underbrace{\sum_{i=0}^{25}25}_{(a)}-\sum_{i=0}^{25}i=25\cdot26-\frac{25\cdot26}{2}=\frac{25\cdot26}{2}=325
$$

noting that the index of the outer summation starts from zero, so in (a) 25 is added 26 times.

**(d)**
$c:=0$
for $i=0$ to 26 step 2
for $j=i$ to 26 step 2
$c:=c+1$
print c

Iteration table:

$$
\begin{array}{cc}
\hline
i & j \\
\hline
0 & \to 0, 2, 4, 6, \dots, 26 \\
2 & \to 2, 4, 6, \dots, 26 \;\;\;\\
4 & \\
6 & \\
\vdots & \\
26 & \to 26 \;\;\; \;\;\; \;\;\; \;\;\; \;\;\; \;\;\; \;\;\\
\hline
\end{array}
$$

Different ways to arrive at the solution:
$\bullet$ The outer loop is executed once for each even number between 0 and 26 (inclusive). The inner loop is executed once for each of the preceding values. Let $j$ be one of such values: it is an even number and the number of even numbers between $j$ and 26 (inclusive) is $\frac{26-j}{2}+1=14-\frac{j}{2}$. Since $j$ takes all even values from 0 to 26, its half takes all values (even and odd) between 0 and 13. Therefore, the number of times the inner loop executes the instruction is 14 the first time, 13 the second, 12 the third, ....1 the fourteenth time.
In conclusion:

$$
c=\sum_{k=1}^{14}k=\frac{14\cdot15}{2}=105
$$

$\bullet$ The outer loop is executed only for even numbers between 0 and 26, that is, for all numbers of the form $2k$, for $k\in\{0,1,2,3,\dots,13\}$. The inner one, for a fixed $i=2k$ for a certain $k$, for all even numbers between $2k$ and $26$, that is, for all numbers of the form $2t$, for $t\in\{k,k+1,\dots,13\}$. For each execution of the inner loop $c$ is incremented by 1. Therefore, we can write:

$$
\sum_{k=0}^{13}\sum_{t=k}^{13}1=^{(1)}\sum_{k=0}^{13}(13-k+1)=^{(2)}\sum_{k=0}^{13}14-\sum_{k=0}^{13}k=^{(3)}14\cdot14-\frac{13\cdot14}{2}=196-91=105
$$

Indeed:
(1) The summation $\sum_{t=k}^{13}1$ adds 1 for each integer between $k$ and 13, inclusive. Thus the result is $13-k+1=14-k$.
(2) We split the summation $\sum_{k=0}^{13}(14-k)=\sum_{k=0}^{13}14-\sum_{k=0}^{13}k$ into two.
(3) The summation $\sum_{k=0}^{13}14$ adds 14 for each integer between 0 and 13, inclusive. Thus the result is $14\cdot(13-0+1)=14\cdot14$. Furthermore, the summation $\sum_{k=0}^{13}k$ is simply the sum of the first 13 natural numbers, so the result is $(13\cdot14)/2$.

Alternatively (more empirical than analytical), try establishing all values taken by $i$ and $j$ by simulating the code execution.

**(e)**
$c:=0$
for $i:=0$ to 20 step 1 do
$j:=0$
while $i+j\le21$ do
$c:=c+1$
$j:=j+1$
print $c$
**Solution.** Let us analyze what happens in the innermost loop as the value of $i$ varies:

- when $i=0$, the while loop is executed once for each integer from 0 (at the first iteration we also have $j=0$) to 21 (and at the end we have $j=21$). Thus variable $c$ is incremented 22 times (once for each value taken by $j$. Note that the first value of $j$ is zero and not 1, which is why the distinct values taken by $j$ are 22 and not 21).
- when $i=1$, the while loop is executed once for each integer from 0 (at the first iteration we still have $j=0$) to 20 (and at the end we have $j=21-1=20$). Thus variable $c$ is incremented 21 times.
- when $i=2$, the while loop is executed once for each integer from 0 (at the first iteration we still have $j=0$) to 19 (and at the end we have $j=21-2=19$). Thus variable $c$ is incremented 20 times.And so on. At a generic iteration, when $i=k$ for some k between 0 and 20, we have

- when $i=k$, the while loop is executed once for each integer from 0 (at the first iteration we still have $j=0$) to $21-k$ (and at the end we have $j=21-k=21-i$). Thus variable $c$ is incremented $21-i+1$ times.The last time the while loop is executed is for $i=20$, and variable $c$ is incremented $21-i+1=21-20+1=2$ times.
  Since $c$ is incremented by 1, the total number of increments gives us the final value of $c$ (which is initialized to zero).
  In conclusion we have

$$
c=\sum_{t=2}^{22}t=\sum_{t=1}^{22}t-1=\frac{22\cdot23}{2}-1=253-1=252
$$

**(g)**$c:=0$
for $i:=0$ to 27 step 2 do
$j:=0$
while $i+j\le28$ do
$c:=c+1$
$j:=j+1$
print $c$
**Solution.** We can reason similarly to the previous exercise, but this time we must pay attention because the step is 2 and not 1.
Thus

- when $i=0$, the while loop is executed once for each integer from 0 (at the first iteration we also have $j=0$) to 28 (and at the end we have $j=28$). Thus variable $c$ is incremented 29 times.
- when $i=2$, the while loop is executed once for each integer from 0 (at the first iteration we still have $j=0$) to 26 (and at the end we have $j=28-2=26$). Thus variable $c$ is incremented 27 times.
- when $i=4$, the while loop is executed once for each integer from 0 (at the first iteration we still have $j=0$) to 24 (and at the end we have $j=28-4=24$). Thus variable $c$ is incremented 25 times.And so on. At a generic iteration, $i$ will be an even number between 0 and 26. Indeed, the next value of $i$ would be 28, which is out of range, so no new iteration of the for loop is executed for this value of $i$.
  Therefore, we can write $i=2k$ for some $k$ between 0 and 13, and we will have:

- when $i=2k$, the while loop is executed once for each integer from 0 (at the first iteration we still have $j=0$) to $28-2k$ (and at the end we have $j=28-2k$). Thus variable $c$ is incremented $28-2k+1=29-2k$ times.The last iteration will be for $k=13$ with an increment of c equal to $29-2\cdot13=3$.
  We have at least two ways to reach the result:

1. We notice that the increment of $c$ is equal to the sum of the odd numbers ranging from 3 (inclusive) to 29 (inclusive). We write a generic odd number as $2j+1$. We are only interested in those for which $j$ goes from 1 to 14, and we have:

$$
\sum_{j=1}^{14}(2j+1)=2\sum_{j=1}^{14}j+\sum_{j=1}^{14}1=2\cdot\frac{14\cdot15}{2}+14=210+14=224
$$

2. We continue with the previous reasoning:

$$
c=\sum_{k=0}^{13}(29-2k)=\sum_{k=0}^{13}29-2\sum_{k=0}^{13}k=29\cdot14-2\cdot\frac{13\cdot14}{2}=406-182=224
$$
