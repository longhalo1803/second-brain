### Q: How large is the input size according to the uniform cost criterion? #card

?
The size of the input is the number of **elements **that constitute it.

📝 Example:
An array/sequence of $n$ numbers has input size $n$;
A matrix of $n \times m$ numbers has input size $n \times m$.
📌 Note: if there are many elements in the input, we do not care about their nature at the single-element level: for example $\sqrt 1$ is "easier" to compute than $\sqrt{2395782369}$, but we do not care if we have many different elements.
