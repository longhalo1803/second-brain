### Q: What are the input and output of a problem in general? And what is the _input instance_? #card

?
**Input**: specifies the type of values (not specific values), and any constraints, from which to start looking for a solution to the problem.
**Output**: specifies the expected result.

📌 Note: a problem can be viewed as a function (which is the algorithm) that maps every possible input configuration $x$ to the corresponding output $f(x)$.
📌 Note 2: an _input instance_ is a specific input configuration where the values satisfy the constraints imposed by the problem.
📝 Examples:
_Input:_
Two integers `a` and `b` such that `a > b`.
_Input instances and output:_
`a=3, b=1` → Yes
`a=0, b=9` → No
