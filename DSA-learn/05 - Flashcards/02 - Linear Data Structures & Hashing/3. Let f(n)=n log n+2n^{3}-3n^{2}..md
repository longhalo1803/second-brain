### Q: 📝 3. Let $f(n)=n \log n+2n^{3}-3n^{2}$.

State which of the following statements are true and which are false.
Prove the statements that you believe to be true.
(a) $f(n)\in\Omega(n \log n)$
(b) $f(n)\in\Theta(n^{3})$
(c) $f(n)\in O(n^{4})$
(d) $f(n)\in\Omega(n^{2})$
(e) $f(n)\in\Omega(n^{5})$ #card
?
We have $f(n)=2n^{3}-3n^{2}+n \log n\le2n^{3}+n \log n\le2n^{3}+n^{3}=3n^{3}$ for $n>0$, so $f(n)\in O(n^{3})$.
Furthermore, $2n^{3}-3n^{2}+n \log n\ge2n^{3}-3n^{2}$.
To prove that $f(n)\in\Omega(n^{3})$, we must show that there exists a constant $c>0$ and an $n_{0}\ge0$ for which the expression holds.
We look for these two constants such that:

```text
{aligned} 2n^3 - 3n^2                // ≥ c n^3 both sides by n^2 > 0 (if n > 0 )
2n - 3                               // ≥ cn
2n - cn                              // ≥ 3
    (2 - c)n                             // ≥ 3 both sides by 2 - c > 0 if c 3$, we have that $2n^{3}-3n^{2}\ge n^{3}\in\Omega(n^{3})$.
Thus:
(a) True;
(b) True;
(c) True;
(d) True;
(e) False.

**In general**, we can use the following rules (to avoid step-by-step calculations):

- if $f(n)\in O(g(n))$, $d(n)\in O(h(n))$, then $f(n)+d(n)\in O(\max\{g(n),h(n)\})$.
Intuitively, the sum is dominated by the term with the higher growth rate.
Thus, in *Exercise 1(d)*, choosing $f(n)=3n^{2}\in O(n^{2})$ and $d(n)=2n \log n\in O(n \log n)$, we can conclude that $f(n)+h(n)=3n^{2}+2n \log n\in O(n^{2})$ because $\max\{g(n),h(n)\}=n^{2}$.
- if $f(n)\in\Omega(g(n))$, $d(n)\in O(h(n))$ and $h(n)$ comes before $g(n)$ in the $O(\cdot)$ table, then $f(n)-g(n)\in\Omega(g(n))$.
Intuitively, in a subtraction, if the subtrahend has a smaller order of magnitude than the minuend, the minuend dominates.
In Exercise 3, we have $f(n)\in O(n^{3})$. Starting back from $2n^{3}-3n^{2}$, we have that $2n^{3}\in\Omega(n^{3})$ and $3n^{2}\in O(n^{2})$. Thus, $f(n)\in\Omega(n^{3})$.
```
