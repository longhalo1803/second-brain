# 🎴 What is an algorithm

> [[00 - Flashcards MOC|🎴 Master MOC]] / [[00 - Linear Data Structures & Hashing MOC|📁 Linear Data Structures & Hashing MOC]]

---

### Q: What is an algorithm? #card

?
A finite sequence of **WELL-ORDERED**, **UNAMBIGUOUS**, and **EFFECTIVELY EXECUTABLE** instructions that, when executed, produce a **RESULT** (solution to the problem or error)\*\* **and **TERMINATE \*\*in a finite amount of time.

📌 Note: this definition of an algorithm does not include:

- non-deterministic or randomized algorithms
- non-terminating algorithms
- online algorithms (incomplete data)
- parallel and distributed algorithms
- quantum algorithms
  📌 Note 2: different algorithms can exist to solve the same problem.

[or]
An algorithm is a procedure that solves a class of problems through a finite number of elementary, clear, and unambiguous instructions.
