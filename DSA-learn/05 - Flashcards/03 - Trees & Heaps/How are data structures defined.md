### Q: How are data structures defined? #card

?
Data structures are a collection of addressable data items with a single name organized in a specific way (e.g., arrays, lists, trees, graphs...), and they are defined by indicating:

- **properties **that their data must satisfy;
- **operations **(called _primitives_) allowed on that data.📌 Note: data structures, from a certain perspective, can be understood as classes in OOP.📝 Example: the stack is a data structure that allows only push (adds a new element to the top of the stack) and pop (remove and return the top element) as operations.
