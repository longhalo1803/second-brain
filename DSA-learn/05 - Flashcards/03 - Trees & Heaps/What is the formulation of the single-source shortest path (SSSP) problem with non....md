### Q: What is the formulation of the single-source shortest path (SSSP) problem with non-negative weights? #card

?
**Input:**

- A graph $G = (V, E)$ (directed or undirected);
- A non-negative cost function $c$ on the edges $c : E \to \mathbb{R}^+$;
- A source node $s \in V$.
  **Output:**
  The **shortest-path tree** rooted at the source node $s$.
