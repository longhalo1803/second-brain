### Q: 📝 4.2 Provide a recursive function `H_Tree(t)` that computes the **height **of an **ordered general tree** (i.e., children are ordered from left to right) $T$ represented with nodes having fields `key`, `firstChild`, and `nextSibling`. #card

?
**Base case: **The tree consists of a leaf (`t.firstChild = NIL`): height is $0$.
**Recursive case: **The tree is not a leaf: we iterate over all its children via the `nextSibling` pointer, recursively computing the height of each subtree rooted at the child plus $1$, and returning the maximum found.

**Pseudocode:**

```text
TreeHeight(T)
    if T = NIL then return {-1}
    else return H_Tree(T)
```

```text
H_Tree(t)
    max := 0
    v := t.firstChild
    while v ≠q NIL do
        h := H_Tree(v) + 1
        if h > max then
            max := h
        v := v.nextSibling
    return max
```
