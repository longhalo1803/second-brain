### Q: 📝📍 3.1 For the following tree, write the resulting expression from each of the following traversals:

- DFS pre-order
- DFS in-order
- DFS post-order
- BFS #card
  ?
- **DFS pre-order (prefix notation):**
  `+ 3 + 2 + 1 * 2 * 1 + 1 - 3 * 2 + 2 + 1 * 2`

- **DFS in-order (infix notation):
  **`+ 1 + 2 * 1 + 1 * 2 + 3 * 2 + 2 - 3 + 1 * 2`

- **DFS post-order (postfix notation / RPN):**
  `+ 1 + 1 * 1 * 2 + 2 + 2 * 2 * 2 + 1 - 3 + 3`

- **BFS (level-order traversal):**
  `+ 3 + 2 - 3 + 1 * 2 * 2 + 1 * 1 + 2 * 2 + 1`
