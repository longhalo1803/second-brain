### Q: What is the difference between a full binary tree and a perfectly balanced binary tree? #card

?
The two definitions of regularity in binary trees are:

➔ **Full binary tree:** a binary tree in which every node has **either exactly zero children or two children** (no node has only one child).

➔ **Perfectly balanced binary tree:** a binary tree in which all leaves are located **at the exact same level** (same depth).

📌 Note: a binary tree can be both full and perfectly balanced (in which case all levels from $0$ to $h$ are completely filled).
