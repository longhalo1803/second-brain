# 🎴 What is the meaning and role of the dist[] and prev[] data structures in BFS

> [[00 - Flashcards MOC|🎴 Master MOC]] / [[00 - Trees & Heaps MOC|📁 Trees & Heaps MOC]]

---

### Q: What is the meaning and role of the `dist[]` and `prev[]` data structures in BFS? #card

?
In the complete BFS code:

- **`dist[u]`**: stores the minimum distance from source node $s$ to node $u$, defined as the _number of edges_ on the shortest path in $G$ between $s$ and $u$.
  • It also serves to track whether a node has been discovered: if $\text{dist}[u] = +\infty$, the node has not yet been discovered.
- **`prev[u]`**: stores the predecessor (or parent) of $u$ in the spanning tree generated by the BFS traversal starting from $s$.
  • It allows tracing back the shortest path from $s$ to any reachable node $u$.
  📌 Practical note: in practical implementation, $+\infty$ can be replaced by any integer value strictly greater than the number of nodes $n$ (e.g., $n+1$).
