## 1. "Context RAM" Dưới Góc Nhìn First Principles

"Context RAM" là một **thuật ngữ ẩn dụ**, mô tả vùng nhớ làm việc tức thời của Agent trong một lượt chạy.

```
 ┌───────────────────────────────────────────────────────────┐
 │                   AGENT RUNTIME / HARNESS                 │
 │                                                           │
 │  1. Đọc Procedural Rules (SKILL.md)                       │
 │  2. Query Semantic Facts (Vector Store / RAG)             │
 │  3. Query Episodic Logs (SQL Time-Series)                 │
 │  4. Nhận User Input + Chat History                        │
 │                                                           │
 │  ───────► Nối chuỗi thành 1 Payload JSON duy nhất ──────► │
 └─────────────────────────────┬─────────────────────────────┘
                               │
                               │ Gửi qua HTTP POST
                               ▼
 ┌───────────────────────────────────────────────────────────┐
 │                   LLM INFERENCE ENGINE                    │
 │                                                           │
 │  Tokenization ──► VRAM Context Window ──► Self-Attention  │
 └───────────────────────────────────────────────────────────┘
```

> [!NOTE]
> - **Context RAM không tự tính toán hay tóm tắt**: Nó là cấu trúc dữ liệu chuỗi (String/JSON) do tầng **Agent Runtime** đóng gói.
> - **Quá trình liên kết logic**: Do chính ma trận Self-Attention của LLM thực thi khi nhận gói Context này.

## 2. Bản Đồ Vị Trí Thực Thi (Execution Topology)

Rất nhiều người nhầm lẫn về việc dữ liệu được xử lý ở đâu. Hãy phân biệt rõ 2 mô hình triển khai:

| Tiêu chí | Mô hình 1: Local Agent (CLI / Desktop) | Mô hình 2: Cloud SaaS Agent |
|---|---|---|
| **Ví dụ** | Claude Code, Cursor, Antigravity, Local Python script | ChatGPT Web, Claude.ai, Perplexity |
| **Nơi chạy Agent Runtime** | **Máy tính cá nhân của User (Local Machine)** | **Máy chủ Backend của Provider** |
| **Nơi lưu File & Local DB** | Ổ cứng máy User (Files, SQLite, Local Chroma) | Cloud Database của nhà cung cấp |
| **Nơi chạy LLM Inference** | Cloud Data Center (OpenAI/Anthropic) hoặc Local Ollama | Cloud Data Center của Provider |

## 3. Cấu Trúc Payload Mẫu Nạp Vào LLM

Khi Agent Runtime chuẩn bị xong "Context RAM", nó gửi một JSON Payload qua API:

```json
{
  "model": "gpt-4o",
  "temperature": 0.2,
  "messages": [
    {
      "role": "system",
      "content": "=== 1. SYSTEM IDENTITY ===\nYou are a Senior AI Architecture Assistant.\n\n=== 2. PROCEDURAL MEMORY (SKILL.MD) ===\nFollow First Principles. Provide exact ASCII diagrams and code.\n\n=== 3. SEMANTIC MEMORY (DURABLE FACTS) ===\n- User: Ryuuki\n- Current Stack: LangGraph, Python 3.12, Obsidian Vault\n\n=== 4. EPISODIC LOGS (RECENT HISTORY) ===\n- [Session 1]: Discussed Agent Harness & Loop Engineering."
    },
    {
      "role": "user",
      "content": "Context RAM được lắp ráp như thế nào?"
    }
  ]
}
```
