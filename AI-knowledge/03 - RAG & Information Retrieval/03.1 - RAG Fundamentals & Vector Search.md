## 1. RAG Là Gì? (First Principles)

RAG (**Retrieval-Augmented Generation**) là kỹ thuật bổ trợ tri thức cho LLM bằng cách **kéo các đoạn văn bản liên quan từ kho dữ liệu bên ngoài** và nhét vào Context Window ngay trước khi sinh câu trả lời:

$$\text{Answer} = \text{LLM}(\text{Prompt} + \text{Retrieved Documents})$$

### Vì sao cần RAG?
1. **Tránh ảo giác (Hallucination)**: LLM dựa trên tài liệu có thực để trả lời thay vì tự suy đoán.
2. **Cập nhật tri thức mới**: Không cần fine-tune lại model đắt đỏ khi dữ liệu công ty thay đổi mỗi ngày.
3. **Bảo mật & Quyền truy cập (RBAC)**: Chỉ truy xuất tài liệu mà người dùng hiện tại có quyền xem.

## 2. Quy Trình RAG Cơ Bản 4 Bước

```
[Dữ liệu thô (PDF, Docs, Web)]
        │
        ▼ 1. Chunking (Cắt đoạn: 500-1000 tokens)
   [Text Chunks]
        │
        ▼ 2. Embedding Model (text-embedding-3, bge-m3)
 [Vector Vectors (1536d / 1024d)]
        │
        ▼ 3. Lưu vào Vector DB (Qdrant, Pinecone, pgvector)
 [Vector Database]
        ▲
        │ 4. User Query ──► Embed Query ──► Top-K Cosine Similarity
        │
 [Top-K Relevant Chunks] ──► Gửi vào Context RAM cùng User Prompt ──► LLM sinh câu trả lời
```

## 3. Các Thuật Toán Khoảng Cách Vector (Distance Metrics)

1. **Cosine Similarity** (Độ tương đồng góc):
   $$\text{Cosine}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$$
   *Thang điểm [-1, 1], phổ biến nhất trong tìm kiếm ngữ nghĩa văn bản.*
2. **Dot Product** (Tích vô hướng): Phù hợp khi vector đã được chuẩn hóa độ dài ($L_2 = 1$).
3. **Euclidean Distance ($L_2$)**: Đo khoảng cách hình học thẳng giữa 2 điểm.

## 4. Vector Databases Phổ Biến

| Vector DB | Đặc điểm | Phù hợp nhất |
|---|---|---|
| **pgvector (PostgreSQL)** | Tích hợp trực tiếp vào SQL Database có sẵn | Đơn giản hóa stack, ACID, Hybrid Search |
| **Qdrant** | Viết bằng Rust, hiệu năng cực cao, hỗ trợ payload filter | Production Agent, High throughput |
| **Pinecone** | Hoàn toàn Serverless, quản lý hoàn toàn trên Cloud | Dự án cần triển khai nhanh, không muốn quản lý hạ tầng |
| **Chroma** | Nhẹ, dễ chạy local bằng Python | Prototyping, Local Agents |
