## 1. Ẩn Dụ: Con Ngựa (The Horse) & Bộ Cương (The Harness)

```
        ┌──────────────────────────────────────────────────────────┐
        │                     AGENT HARNESS                        │
        │                                                          │
        │   ┌──────────────────────────────────────────────────┐   │
        │   │               THE HORSE (LLM Engine)             │   │
        │   │  - Thông minh vô hạn, biết tri thức nhân loại    │   │
        │   │  - Sinh từ theo xác suất (Probabilistic)          │   │
        │   │  - Ngẫu nhiên (Randomness), không biết bạn      │   │
        │   └────────────────────────┬─────────────────────────┘   │
        │                            │                             │
        │   ┌────────────────────────▼─────────────────────────┐   │
        │   │             BỘ CƯƠNG KIỂM SOÁT (Harness)         │   │
        │   │  - Context RAM / Working Memory Manager          │   │
        │   │  - Tri-Memory Layer (Procedural, Semantic, Epis.) │   │
        │   │  - Tool Registry & Execution Environment         │   │
        │   │  - Loop Controller & End-Loop Guardrails         │   │
        │   │  - LLMOps: Tracing, Evaluation & Self-Correction │   │
        │   └──────────────────────────────────────────────────┘   │
        └──────────────────────────────────────────────────────────┘
```

- **LLM thuần túy**: Giống một chú ngựa chiến dũng mãnh nhưng hoang dã. Nếu thả rông, nó sẽ chạy theo hướng ngẫu nhiên dựa trên xác suất từ ngữ, có thể gây hại hoặc đưa ra thông tin ảo giác.
- **Agent Harness**: Là tập hợp các công cụ điều khiển (yên cương, dây cương, bàn đạp) bao bọc quanh LLM. Harness quyết định khi nào cho ngựa chạy, chạy hướng nào, cung cấp thức ăn (Context/Memory), và khi nào phải dừng lại.

---

## 2. Các Thành Phần Trọng Yếu Của Một Harness Chuẩn

1. **Context & State Manager**: Chuẩn bị Context RAM, quản lý biến trạng thái (State) qua các bước chạy.
2. **Tool Registry & Executor**: Quản lý danh sách Function/Tool, kiểm tra kiểu dữ liệu (Schema validation), thực thi an toàn trong Sandbox.
3. **Loop Controller**: Điều phối vòng lặp suy luận - hành động (ReAct loop), theo dõi số bước thực thi.
4. **Safety & Guardrails**: Chặn các câu lệnh nguy hiểm, yêu cầu phê duyệt khi rủi ro cao.
5. **Observability Hooks**: Gửi log và metrics sang hệ thống Tracing (LangFuse/LangSmith).
