## 1. Triết Lý Của PydanticAI

PydanticAI là framework do đội ngũ sáng lập **Pydantic** phát triển, mang lại trải nghiệm lập trình Agent kiểu mẫu với các nguyên tắc:
1. **Type Safety (An toàn kiểu dữ liệu)**: Tận dụng hoàn toàn Type Hints của Python và Pydantic models.
2. **Structured Outputs**: Đảm bảo 100% LLM trả về đúng schema đã định nghĩa mà không bị lỗi parse JSON.
3. **Dependency Injection**: Tiêm phụ thuộc (Database connections, User context) vào các Tool functions một cách tự nhiên và an toàn.

## 2. Ví Dụ Triển Khai Type-Safe Agent

```python
from pydantic import BaseModel, Field
from pydantic_ai import Agent, RunContext
from dataclasses import dataclass

@dataclass
class UserContext:
    user_id: str
    is_premium: bool

class SearchResult(BaseModel):
    title: str = Field(description="Tiêu đề bài viết")
    confidence: float = Field(ge=0.0, le=1.0, description="Độ tin cậy")
    summary: str = Field(description="Tóm tắt 1 câu")

# Khởi tạo Agent với Input Context và Output Type cụ thể
agent = Agent(
    'openai:gpt-4o',
    deps_type=UserContext,
    result_type=SearchResult,
    system_prompt="Bạn là chuyên gia phân tích dữ liệu."
)

@agent.tool
def get_user_data(ctx: RunContext[UserContext]) -> str:
    """Truy xuất thông tin người dùng từ context tiêm vào."""
    return f"User {ctx.deps.user_id} - Premium: {ctx.deps.is_premium}"
```

## 3. Khi Nào Chọn LangGraph vs PydanticAI?

| Tiêu chí | LangGraph | PydanticAI |
|---|---|---|
| **Mô hình luồng** | Đồ thị phức tạp, đa nhánh, song song | Hướng luồng tuyến tính + Tool calling hướng hàm |
| **Độ phức tạp** | Cao, cần học mô hình StateGraph | Thấp, quen thuộc với dân viết FastAPI/Python chuẩn |
| **Thế mạnh** | Hệ thống Multi-agent lớn, Human-in-the-loop, Time-travel | API backend, Microservices, Structured Data Extraction |
