## 1. Sự Khác Biệt: LangChain vs LangGraph

- **LangChain (Classic)**: Tập trung vào chuỗi tuần tự **DAG (Directed Acyclic Graphs)** thông qua LCEL (LangChain Expression Language). Phù hợp cho RAG đơn giản, không phù hợp cho Agent cần vòng lặp vô hạn hoặc phân nhánh phức tạp.
- **LangGraph**: Mở rộng cho phép xây dựng **Cyclic Graphs (Đồ thị có chu kỳ)**. Đây là framework tiêu chuẩn công nghiệp hiện nay để xây dựng Agent Harness hoàn chỉnh với khả năng quản lý State, Checkpointing và Human-in-the-loop.

## 2. 4 Khái Niệm Cốt Lõi Của LangGraph

```
 ┌─────────────────────────────────────────────────────────────┐
 │                         LANGGRAPH                           │
 │                                                             │
 │   ┌──────────────┐      Conditional Edge      ┌───────────┐ │
 │   │  LLM Node    ├───────────────────────────►│ Tool Node │ │
 │   └──────▲───────┘                            └─────┬─────┘ │
 │          │                                          │       │
 │          └────────────────── Cycle ─────────────────┘       │
 │                                                             │
 │   [State Management]          [Checkpointer (Postgres/RAM)] │
 └─────────────────────────────────────────────────────────────┘
```

1. **State (Trạng thái trung tâm)**: Cấu trúc dữ liệu (TypedDict hoặc Pydantic) lưu trữ toàn bộ biến số của Agent qua từng bước (Messages, Variables, Iterations).
2. **Nodes (Các đỉnh xử lý)**: Các hàm Python nhận vào State hiện tại, thực thi logic (gọi LLM hoặc chạy tool) và trả về State cập nhật.
3. **Edges (Các cạnh điều hướng)**:
   - *Normal Edge*: Chuyển thẳng từ Node A sang Node B.
   - *Conditional Edge*: Hàm điều kiện kiểm tra State để quyết định nhảy sang Node tiếp theo nào (ví dụ: nếu có `tool_calls` thì nhảy sang `tools`, nếu không thì nhảy sang `END`).
4. **Checkpointers**: Cơ chế lưu vết từng phiên bản của State vào Database sau mỗi bước, cho phép tính năng **Time-travel debugging** và **Human-in-the-loop pause/resume**.

## 3. Code Mẫu Một Agent Cơ Bản Bằng LangGraph

```python
from typing import TypedDict, Annotated, Sequence
from langchain_core.messages import BaseMessage
from langgraph.graph import StateGraph, END
from langgraph.prebuilt import ToolNode
import operator

# 1. Định nghĩa State
class AgentState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], operator.add]

# 2. Định nghĩa Nodes
def call_model(state: AgentState):
    response = model_with_tools.invoke(state["messages"])
    return {"messages": [response]}

# 3. Điều kiện phân nhánh (Conditional Edge)
def should_continue(state: AgentState):
    last_message = state["messages"][-1]
    if last_message.tool_calls:
        return "tools"
    return END

# 4. Khởi tạo Graph
workflow = StateGraph(AgentState)
workflow.add_node("agent", call_model)
workflow.add_node("tools", ToolNode(tools))

workflow.set_entry_point("agent")
workflow.add_conditional_edges("agent", should_continue)
workflow.add_edge("tools", "agent")

app = workflow.compile()
```
