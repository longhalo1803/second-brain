AI Agent Harness & Loop Engineering: Quick Reference

Dựa trên bài giảng của Sean (John) | Tri-Memory, Loop Control, LLMOps & Evals

1. Ẩn Dụ Cốt Lõi: The Horse & The Harness

  • The Horse (LLM): Động cơ thông minh, sinh từ theo xác suất (probabilistic), ngẫu nhiên, không có tri thức về bối cảnh cá nhân/doanh nghiệp.
  • The Harness (Bộ cương): Khung kiểm soát bao quanh LLM (LangGraph, PydanticAI) để định hướng hành vi, cấp phát bộ nhớ, hạn chế tính ngẫu nhiên.

2. Bảng Phân Loại Trí Nhớ (Tri-Memory Architecture)

Tầng Trí Nhớ Bản Chất Lưu Trữ Cơ Chế Truy Xuất
Context RAM Tạm thời (Ephemeral) LLM Window In-memory trực tiếp
Procedural Quy trình / Kỹ năng Markdown (SKILL.md), DB Inject vào System Prompt
Semantic Durable Facts, User Profile Vector Store RAG (Top-K Semantic Search)
Episodic Time-series chat & events SQL DB + Vector DB Hybrid: SQL (Recency) + RAG (Relevance)

* Tối ưu hóa: Dùng Summarizer Agent (chạy model nhỏ, rẻ) tự động nén lịch sử mỗi $N$ cuộc hội thoại -> trích xuất facts -> lưu vào Semantic Memory.

3. Loop Engineering & End-Loop Guardrails

User Request -> LLM Planning -> [Tool Call -> Observation -> Tool Call] -> End-Loop Guardrail -> Final Response
  • Mục đích vòng lặp (Loop): Cho phép tác tử gọi nhiều công cụ liên tiếp để giải quyết bài toán phức tạp.
  • End-Loop Guardrails: Tiêu chí dừng bắt buộc để tránh vòng lặp vô hạn (Infinite Loop) và lãng phí token:
    • Điều kiện hoàn thành mục tiêu (Task completion criteria).
    • Xác nhận từ con người (Human-in-the-loop) khi gặp tác vụ nhạy cảm / hoàn tiền.
    • Proactive alerts khi chờ cấp quyền.

4. LLMOps & Evaluation: Vòng Phản Hồi Tự Tiến Hóa

  1. Tracing (LangFuse / LangSmith): Ghi lại Trace Tree: Query -> RAG context -> Tool calls -> Latency & Token metrics.
  2. Evaluation: LLM-as-a-Judge + Deterministic Assertions đánh giá độ chính xác và sức khỏe hệ thống.
  3. Diagnosis: Phân tích nguyên nhân gốc khi latency tăng hoặc tool thất bại.
  4. Continuous Deployment: Tự động cập nhật System Prompt, Hyperparameters hoặc kích hoạt Coding Agent sửa code.
