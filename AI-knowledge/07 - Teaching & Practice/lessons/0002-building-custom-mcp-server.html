Bài Học 0002: Model Context Protocol (MCP) & Tự Tạo MCP Server

Hiểu sâu bản chất USB-C cho AI | Kiến trúc Client-Server | Hướng dẫn tạo Server Python với FastMCP

1. Tại Sao Thế Giới Cần MCP?

Trước khi có MCP, mỗi ứng dụng AI kết nối với Database hoặc API theo cách thủ công (viết glue code, viết prompt dài mô tả endpoint). Nếu API đổi hoặc model đổi, toàn bộ tích hợp bị gãy.

MCP (Chuẩn mở do Anthropic khởi xướng) đóng vai trò như cổng USB-C cho AI: cung cấp giao thức chuẩn hóa để mô hình AI tự khám phá và sử dụng công cụ một cách tự động.

2. Ba Khối Năng Lực (3 Primitives Của MCP)

1. TOOLS (Hành Động)

Thực thi hàm

Hàm mà Model có thể chủ động gọi kèm tham số (gửi email, query database, tính toán).

2. RESOURCES (Dữ Liệu)

Tài nguyên chỉ đọc

Dữ liệu ngữ cảnh thụ động định danh bằng URI (file log, schema bảng, tài liệu PDF).

3. PROMPTS (Mẫu Chỉ Dẫn)

Mẫu tương tác

Các template prompt tạo sẵn giúp người dùng kích hoạt tác vụ cụ thể nhanh chóng.

3. 4 Bước Tự Viết MCP Server Cho Riêng Bạn

  1. Cài đặt: pip install mcp
  2. Viết code với FastMCP: 
    from mcp.server.fastmcp import FastMCP

mcp = FastMCP("My-Server")

@mcp.tool()
def read_vault_note(file_name: str) -> str:
    """Đọc nội dung một ghi chú trong Obsidian Vault."""
    with open(f"/path/to/vault/{file_name}", "r") as f:
        return f.read()

if __name__ == "__main__":
    mcp.run(transport="stdio")
  3. Test với MCP Inspector: npx @modelcontextprotocol/inspector python3 server.py
  4. Cấu hình vào Claude Desktop / Cursor: Thêm lệnh chạy vào file claude_desktop_config.json.
