1. Nguyên Lý Đầu Tiên: LLM Là Gì Trong Thực Tế?

Hãy loại bỏ mọi từ ngữ bóng bẩy. Ở mức cơ bản nhất:

$$y = \text{LLM}(x_1, x_2, \dots, x_N)$$
  • Stateless Function (Không có trạng thái): LLM không có ký ức sau khi tắt phiên. Nó chỉ là một file trọng số (Weights Matrix) nằm trên RAM của card đồ họa (GPU VRAM).
  • Input $x$: Một mảng số nguyên biểu diễn các từ/ký tự (Tokens).
  • Context RAM thực chất là gì? Nó không phải là một con chip hay một AI phụ. Nó chỉ là chuỗi văn bản (String Payload) được phần mềm điều khiển (Harness) lắp ghép lại từ nhiều nguồn rồi gửi cho LLM.

2. Logic Xử Lý Nằm Ở Đâu: Máy User Hay Máy Chủ Provider?

TẦNG 1: AGENT RUNTIME (ORCHESTRATOR)

Nơi Lắp Ghép Context RAM

Nơi chạy:

  • Máy của User: Nếu dùng Antigravity, Claude Code, Cursor, Local Python script.
  • Cloud Server ứng dụng: Nếu dùng ChatGPT Web, Perplexity (server backend của họ).

Nhiệm vụ: Code thông thường (Python/Node.js) thực hiện: Đọc file SKILL.md, query Vector DB, query SQL, ghép chuỗi JSON.

TẦNG 2: LLM PROVIDER

Nơi "Xào Nấu" Trí Tuệ (Inference)

Nơi chạy:

  • Data Center của Provider: OpenAI, Anthropic, Google Cloud GPU clusters.
  • Hoặc Local GPU: Nếu chạy Ollama / vLLM trên máy bạn.

Nhiệm vụ: Nhận chuỗi JSON từ Tầng 1 qua API, chạy ma trận Self-Attention để liên kết dữ liệu giữa các câu và sinh câu trả lời.

3. Model LLM Hứng Cái Gì Từ Context RAM?

Context RAM không tự "suy nghĩ" hay "tóm tắt trước" (trừ khi lập trình viên chủ động gọi một Summarizer Agent trước đó). Model LLM nhận toàn bộ gói JSON nguyên khối:

POST https://api.openai.com/v1/chat/completions
{
  "model": "gpt-4o",
  "messages": [
    {
      "role": "system",
      "content": "[PROCEDURAL]: Làm theo các bước sau...\n[SEMANTIC FACTS]: User tên là Ryuuki, thích First Principles...\n[EPISODIC LOGS]: Hôm qua đã thảo luận về Harness..."
    },
    {
      "role": "user",
      "content": "Context RAM hoạt động thế nào?"
    }
  ]
}

Quá trình "xào nấu" thực sự:

Khi toàn bộ đoạn text trên biến thành Tokens trên GPU, cơ chế Self-Attention sẽ cho phép từ "Ryuuki" trong Semantic Memory kết nối với từ "tôi" trong câu hỏi của User, từ đó sinh ra câu trả lời chính xác.
