## 1. Procedural Memory Là Gì?

Procedural Memory (Bộ nhớ thủ tục) tương tự như phản xạ có điều kiện hoặc kỹ năng của con người (như cách đi xe đạp, cách viết code sạch).

Trong hệ thống AI Agent:
- Procedural Memory là tập hợp các **chỉ dẫn (Instructions)**, **quy trình từng bước (Step-by-step workflows)**, và **kỹ năng chuyên biệt (Agent Skills)** hướng dẫn Agent cách giải quyết một bài toán cụ thể.

---

## 2. Tiêu Chuẩn Thiết Kế Skill File (`SKILL.md`)

Một Skill file chuẩn (được áp dụng trong các harness hiện đại như Antigravity, Claude Code, Goose) gồm 2 phần:
1. **YAML Frontmatter**: Khai báo metadata, trigger keywords, công cụ yêu cầu.
2. **Markdown Body**: Chỉ dẫn chi tiết, luồng xử lý lỗi, ví dụ input/output.

```markdown
---
name: database-migration-expert
description: Kỹ năng tạo và chạy database migration an toàn cho PostgreSQL.
triggers: ["migrate database", "thêm cột", "tạo bảng", "db schema"]
required_tools: ["run_command", "view_file", "write_to_file"]
---

# Database Migration Expert Skill

## 1. Nguyên Tắc Bắt Buộc
- KHÔNG BAO GIỜ chạy lệnh `DROP TABLE` mà không có xác nhận từ người dùng.
- Luôn tạo script `down` (rollback) song song với script `up`.

## 2. Quy Trình Thực Thi
1. Kiểm tra trạng thái hiện tại bằng lệnh `alembic current`.
2. Tạo file migration mới: `alembic revision --autogenerate -m "..."`.
3. Đọc lại file migration và review câu lệnh SQL phát sinh.
4. Chạy `alembic upgrade head` và xác nhận log thành công.
```

---

## 3. Dynamic Skill Injection (Nạp Kỹ Năng Động)

Thay vì nhét hàng trăm file `SKILL.md` vào System Prompt làm tràn Context Window và tốn chi phí:
1. **Index giai đoạn khởi động**: Chỉ nạp tên và mô tả ngắn của tất cả skills (khoảng 10-20 tokens/skill).
2. **Trigger Matching**: Khi người dùng yêu cầu bài toán liên quan, Agent Harness tự động đọc toàn bộ nội dung của file `SKILL.md` tương ứng và inject vào context của phiên chạy đó.
