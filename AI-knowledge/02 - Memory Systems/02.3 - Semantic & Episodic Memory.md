## 2. Chiến Lược Truy Xuất (Retrieval Strategies)

### 2.1. Semantic Memory (Durable Facts)
- **Cấu trúc dữ liệu**: Vector Embeddings + Document Metadata.
- **Phương pháp truy xuất**: **Vector Cosine Similarity (Semantic RAG)**.
- **Khi nào dùng?** Khi cần tìm kiếm các sự thật liên quan tới câu hỏi bất kể thời gian xảy ra khi nào.

### 2.2. Episodic Memory (Time-Series Logs)
- **Cấu trúc dữ liệu**: SQL Relational Table (`id`, `session_id`, `timestamp`, `role`, `message`, `embedding`).
- **Phương pháp truy xuất**: **Hybrid Search (SQL + Vector)**.
  - *Ví dụ 1 (Lọc thời gian)*: "10 tin nhắn gần nhất với User A" $\to$ Chạy lệnh SQL:
    ```sql
    SELECT * FROM chat_history 
    WHERE user_id = 'A' 
    ORDER BY created_at DESC LIMIT 10;
    ```
  - *Ví dụ 2 (Lọc ngữ nghĩa kết hợp thời gian)*: "Các khiếu nại về chất lượng trong 30 ngày qua" $\to$ Kết hợp SQL filter `created_at >= NOW() - INTERVAL '30 days'` với Vector Similarity search.

## 3. Kiến Trúc Database Đề Xuất (Storage Engine)

```sql
-- Bảng Episodic Memory (Time-series)
CREATE TABLE episodic_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id VARCHAR(64) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    role VARCHAR(16) NOT NULL, -- 'user' | 'assistant' | 'tool'
    content TEXT NOT NULL,
    embedding VECTOR(1536) -- Hỗ trợ pgvector
);

-- Bảng Semantic Memory (Durable Facts)
CREATE TABLE semantic_facts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    subject VARCHAR(128) NOT NULL, -- e.g. 'user_profile', 'product_policy'
    fact_text TEXT NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    embedding VECTOR(1536)
);
```
